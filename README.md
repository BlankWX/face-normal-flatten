# Face Normal Flatten · 脸部法线平面化

简体中文 · [English](README_EN.md)

让面部中心使用统一的**着色法线**，并在外缘平滑过渡回原法线，适合风格化角色的面部着色。插件不移动顶点，不改变脸部几何形状。

**版本：1.1.0** · **许可证：GPL-3.0-or-later** · **最低 Blender：5.2**

**作者：BlankWX**

目前实际验证环境为 **Blender 5.2.2 LTS**；其他版本尚未验证。当前界面为中文。

## 安装

1. 从仓库的 Releases 页面下载 `face_normal_flatten-1.1.0.zip`；也可以从源码自行构建。
2. 在 Blender 的 **偏好设置 → 插件 → 从磁盘安装** 中选择该 ZIP，启用 **Face Normal Flatten / 脸部法线平面化**。
3. 在物体模式选中脸部网格，按 **N** 打开 3D 视图侧栏，进入 **脸部法线**。
4. 点击 **应用 / 更新平面化**。调整参数后再次点击该按钮，保存 `.blend` 即可保留效果和原法线备份。

安装时使用插件 ZIP。带 `-source` 后缀的 ZIP 是完整仓库源码包。

## 模型准备

- **独立的开放脸片**：通常可直接使用自动朝向，两个顶点组字段留空。
- **脸部与整头或身体相连**：为需要处理的面部建立顶点组，填入“作用范围顶点组”。只有组内权重大于 `0.5` 的顶点组成的完整面片参与计算。
- **边界识别不符合预期**：指定“根部顶点组”，替代自动外缘识别。每个处理的连通部分都需要根部。
- **局部坐标轴不同**：选择正负轴或自定义面部朝向；下颌调节还可以指定模型上方向。

自动模式会跳过眼睛和嘴巴的内孔，避免在这些位置生成额外的保留环。

## 参数

| 选项 | 作用 |
| --- | --- |
| 面部朝向 | 自动计算、指定局部坐标轴，或填写任意局部方向。 |
| 过渡宽度 | 相对于面部宽度的过渡带宽度。越大过渡越柔和，完全平面化区域越小。默认 `0.30`。 |
| 根部保留宽度 | 外缘保留原法线的带宽，相对于面部宽度。默认 `0.02`。 |
| 下颌过渡下移 | 正值把下颌过渡压向轮廓下缘，负值向上展开；`0` 精确保留旧效果。默认 `0`。 |
| 模型上方向 | 下颌判断使用的局部上方向，默认 `+Z`，下颌偏移非零时显示。 |
| 作用范围顶点组 | 限定处理的面部面片。独立脸片可留空。 |
| 指定根部顶点组 | 替代自动外缘，组内权重大于 `0.5` 的顶点作为根部。 |
| 恢复原始法线 | 恢复原法线存储，以及仍存在的原 Normal Edit 修改器开关。 |

下颌偏移按面部宽度比例计算，不代表固定的世界坐标移动距离。可从 `0.05` 左右开始观察，再按模型调整；上部权重与保留根部保持不变。

## 保留与恢复

- 不修改几何、UV、材质、形态键或骨骼权重。
- 使用角点法线，保留原有法线分裂。
- 每次更新都读取首次备份，避免重复应用后累积修改。
- 保存后的效果不依赖插件持续运行；再次调节或恢复需要启用插件。
- 原法线、原编码数据和拓扑签名随 `.blend` 保存。
- 应用时停用目标网格的 Normal Edit 修改器，恢复时还原仍存在的修改器开关。

## 适用范围

自动模式适合朝向一致、外轮廓清晰的开放脸片。闭合头部或完整角色需要指定面部范围，或者手动选择根部和方向；插件不会自动从任意人物网格识别人脸区域。

非流形、断裂边界、低可信度自动边界、共享网格数据、没有平面中心的参数会明确报错。若多个物体共用同一个网格，先将网格设为单用户。

**修改拓扑前先恢复原法线。** 如果备份后已经改动拓扑，插件会拒绝旧备份的错误映射；应撤销拓扑修改或使用文件备份。

过于稀疏的网格会影响沿网格边计算的距离。原模型的几何缝隙、材质色差、贴图与法线贴图，以及后续写入法线的修改器，仍会影响最终画面。合成模型测试不等于对任意真实角色的效果保证。

## 开发与验证

仅运行纯 Python 测试不需要安装 Blender，也不需要额外 Python 包：

```sh
python -m unittest discover -s tests -v
```

使用独立后台 Blender 运行合成模型集成测试：

```sh
python tools/test_blender.py --blender blender
```

`--blender` 可以填写本机 Blender 可执行文件路径。测试不连接正在编辑的场景，不依赖开发时使用的角色文件。

构建可安装插件与公开源码包：

```sh
python tools/package_addon.py
```

输出位于 `dist/`：

- `face_normal_flatten-1.1.0.zip`：安装到 Blender 的插件包。
- `face_normal_flatten-1.1.0-source.zip`：含文档、测试和 CI 的公开源码包。
- `SHA256SUMS`、`release-manifest.json`：校验与文件清单。

打包器使用明确的公开文件清单，并检查个人电脑路径与本地连接地址。角色数据、截图、旧调试脚本和生成报告不在清单内。

CI 运行纯 Python 和打包检查并上传构建产物，**不运行 Blender 集成测试**。本地开发已检查真实示例的表情、转头、恢复与保存重开；相关角色文件与截图不随仓库分发。
