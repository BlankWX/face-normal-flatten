# v1.2.3 · 一键重置网格法线

在 3D 视图侧栏的“脸部法线”面板中，点击“恢复原始法线 / 解除过渡”下方的 **重置所选网格法线**。物体模式对所有选中网格恢复自动法线，编辑模式对所选元素执行 Blender 原生的“重置矢量”。操作支持撤销，无需事先创建插件备份。

该操作作用于基础网格。已有法线编辑修改器继续参与计算，已有插件备份仍可用于恢复。

## English

The new panel button resets base normals for all selected meshes in Object Mode. In Edit Mode it runs Blender's native Reset Vectors on the current selection. Undo and existing plug-in backups remain available.
