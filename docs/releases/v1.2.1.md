# v1.2.1 · 下颌接缝阴影修复

自动外缘现在能跳过下巴处折返且两侧完全重合的接缝。缝口仍属于外缘，缝内顶点按到真实外缘的距离参与渐变。动态和静态模式均使用这一规则。

边界识别朝向默认为物体局部 **-Y**，移除了自动朝向选项。旧文件中的自动朝向按 -Y 处理，显式指定的坐标轴和自定义方向沿用原值。新建法线编辑修改器默认使用 **径向 / 复制**。

安装 `face_normal_flatten-1.2.1.zip` 后，在已有动态脸片上点击一次 **创建 / 更新动态过渡** 即可重算权重。复用已有修改器时沿用它的混合模式，可在面板中切换为“复制”。

## English

Automatic contour detection skips a slit when its two banks retrace the same vertex positions from a shared tip. This fixes a localized chin shadow while preserving the transition at the actual rim. Existing dynamic setups can use **Create / Update Dynamic Transition** to recalculate from their saved backup.

The direction now defaults to local **-Y**. Saved manual directions retain their values. Newly created Normal Edit modifiers use **RADIAL / COPY**.
