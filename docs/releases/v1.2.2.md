# v1.2.2 · 插件模块重构

网格数据适配、法线备份和应用流程现在由独立模块负责。静态与动态模式共用同一套过渡计算；动态回滚与原法线恢复共用底层编码读写函数。

已有脚本可继续通过 `face_normal_flatten.apply_effect`、`apply_flatten` 和 `restore_normals` 调用插件。v1.2.1 场景可直接打开，已生成的过渡组和法线备份可继续使用。

## English

Mesh adaptation, normal backups, and workflow dispatch now live in separate modules. Existing package-level scripting entry points and saved mesh data remain compatible. Install `face_normal_flatten-1.2.2.zip` through Blender Preferences.
