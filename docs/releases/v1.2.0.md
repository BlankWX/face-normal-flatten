# Face Normal Flatten v1.2.0 · 动态法线过渡

作者 / Author: **BlankWX** · **GPL-3.0-or-later**

## 中文

v1.2.0 新增默认的**动态修改器过渡**模式。保留骨架之后的原生 Normal Edit（法线编辑），让法线随姿态和表情重新计算，同时通过渐变权重保留面部到下颌、脸片根部的平滑过渡。

### 主要变化

- 已有法线编辑保留模式、目标、偏移和混合设置；必要时移至所有骨架修改器之后。
- 没有法线编辑时创建真正的原生修改器：径向、相加、系数 1、最大角度 180°、偏移 `(0, 2, 0)`、锁定多边形法线、无目标物体。
- 自动生成独立过渡顶点组。中心保留完整修改器效果，外缘回到传入法线；原修改器蒙版（含反转）会乘入权重，原组不改动。
- 保留过渡宽度、根部保留宽度、下颌过渡下移、作用范围与指定根部控制。
- 从 v1.0/v1.1 静态结果迁移时，先恢复文件内备份的原法线，避免旧静态结果与动态效果叠加。
- 支持重复更新、解除过渡和保存后重开；旧版静态模式仍可使用。播放动画无需每帧运行插件脚本。

### 安装与升级

1. 使用 **`face_normal_flatten-1.2.0.zip`** 安装到 Blender，并启用插件。升级前保留 `.blend` 备份，更新插件后重启 Blender。
2. 选中脸部网格，在 N 侧栏的“脸部法线”中选择“动态修改器过渡”。已有多个法线编辑时，明确选择要接管的修改器。
3. 点击“创建 / 更新动态过渡”。旧静态备份会自动用于迁移，无需先应用或删除原生修改器。
4. 调整过渡或下颌参数后再次点击更新。修改器偏移和混合参数即时生效。确认效果后保存项目。

带 **`-source`** 后缀的 ZIP 用于开发，不用于 Blender 安装。附件 `SHA256SUMS` 和 `release-manifest.json` 用于核对构建内容。

### 验证与适用范围

- Blender **5.2.2 LTS**：**22 项集成测试通过**（12 项静态/通用、10 项动态）。
- **40 项 Python 测试通过**（34 项算法、6 项打包）。
- 真实角色示例检查了转头、表情、缺少修改器时创建、恢复与保存重开；这些检查仅覆盖该示例的选定状态。

动态中心保留原生修改器效果，不保证法线完全平行，也不会自动追踪灯光。预设偏移使用局部坐标，不同模型可能需要调整。自动识别适合开放脸片；完整头部或身体需要指定面部范围。动态权重作用于顶点，手动根部应覆盖范围周界以保护相邻面片。其他 Blender 版本及任意角色的效果尚未全面验证。

## English

Version 1.2.0 adds **dynamic modifier transition** as the default mode. A native Normal Edit runs after the armature and reevaluates with poses and expressions. A smooth vertex-group mask blends its influence back to incoming normals at the outer face roots and jaw.

### Changes

- Retain an existing modifier's mode, target, offset and mixing settings, moving it after all Armature modifiers when needed.
- Create a native modifier when absent: RADIAL, ADD, factor 1, 180-degree limit, offset `(0, 2, 0)`, polygon-normal lock enabled, no target.
- Multiply any previous modifier mask, including inversion, into a separate transition group without editing the original group.
- Keep the transition width, root band, signed jaw offset, region and explicit-root controls.
- Migrate v1.0/v1.1 static results from their saved original-normal backup. Support repeated updates, restoration and saved-file persistence. Legacy static mode remains available.

### Upgrade

Back up the `.blend`, install **`face_normal_flatten-1.2.0.zip`**, and restart Blender. Select the face mesh, choose **动态修改器过渡** in the **脸部法线** sidebar, and click **创建 / 更新动态过渡**. Select the intended Normal Edit explicitly if several exist. Migration uses the original backup automatically. Update again after changing transition controls, then save the project.

The **`-source.zip`** archive is for development. Use `SHA256SUMS` and `release-manifest.json` to verify the release files.

### Validation and limits

**40 Python tests and 22 Blender integration cases passed**, with Blender integration tested on **5.2.2 LTS**. Selected real-character poses, an expression, missing-modifier creation, restoration and saved-file reopening were also checked locally. CI runs Python/package checks only.

Dynamic mode preserves native modifier behavior; it does not guarantee parallel normals or automatically follow lights. The local-space offset may need adjustment for a different asset. Automatic roots target open face patches. Connected heads or bodies need a face region; explicit roots should cover its perimeter because dynamic weights affect shared vertices. Other Blender versions and arbitrary characters have not been fully validated. Character assets and private captures are excluded.
